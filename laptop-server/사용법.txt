[ 계남중 파일업다운 · 학교 노트북 서버 사용법 ]

언제 쓰나요?
 - 학교 와이파이가 0.peerjs.com(공개 연결 서버)을 막아서 앱이 연결되지 않을 때
 - 이 노트북이 학생 태블릿과 같은 와이파이(같은 대역)에 있어야 합니다.
 - 앱(APK) v3.18 이상에서만 쓸 수 있습니다. (웹 버전은 불가)

1. 처음 한 번만: 노트북에 Node.js 설치
   https://nodejs.org 에서 LTS 버전을 받아 설치합니다. (설치가 막혀 있으면 정보부에 문의)

2. 서버 켜기
   이 폴더의 [시작.bat]을 더블클릭합니다.
   처음에는 부품 설치 때문에 인터넷이 필요하고 1분쯤 걸립니다.
   까만 창에 "서버가 켜졌습니다"와 노트북 IP 주소가 나옵니다. 창을 닫으면 꺼집니다.
   이 창은 2초마다 새로고침되며 다음을 보여 줍니다.
    - 현재 접속 대수(방장/게스트), 최고 접속 대수, 최근 1분 새 접속 건수
    - 방장이 접속해 있는 방 목록(#방코드)
    - 최근 접속·퇴장 기록 12줄
   (게스트는 방 코드가 서버에 전달되지 않아서 방별 인원은 알 수 없고 전체 대수만 보입니다.)

3. 윈도우 방화벽 열기 (처음 한 번만, 관리자 권한 CMD)
   netsh advfirewall firewall add rule name="gyenam-peer-9000" dir=in action=allow protocol=TCP localport=9000
   (또는 서버를 켤 때 뜨는 "허용" 창에서 [액세스 허용]을 누릅니다.)

4. 앱에서 서버 바꾸기
   앱 왼쪽 위 제목 [계남중 파일업다운]을 12번 누릅니다 → [교사 설정]
   → 노트북 IP 주소와 포트(9000) 입력 → [연결 시험] → 성공하면 [노트북 서버로 전체 적용]
   학생 기기는 30초 안에 같은 방으로 다시 접속합니다.

5. 원래대로 되돌리기
   [교사 설정] → [기본 서버(0.peerjs.com)로 전체 되돌리기]

주의
 - 노트북이 절전/덮개 닫힘으로 잠들면 서버도 멈춥니다. 전원 옵션에서 절전을 끄세요.
 - IP 주소는 와이파이를 다시 연결하면 바뀔 수 있습니다. 바뀌면 4번을 다시 하세요.
 - 노트북과 태블릿이 서로 통신하지 못하는 망(교사망/학생망 분리, 기기 간 격리)이면 쓸 수 없습니다.
   [연결 시험]이 실패하면 이 경우일 수 있으니 무선AP 담당자에게 문의하세요.
